# Third-party references

Horizon was developed from public documentation and behavioral research. No third-party exploit scripts or JavaScript libraries are vendored in this repository.

- [`get-air/vizio`](https://github.com/get-air/vizio) documents SmartCast endpoints and Conjure launch behavior. Its repository identifies the MIT License. Horizon uses it as a protocol reference; no code was copied.
- [SocialVibe `truex-ctv-web-reference-app`, Vizio README](https://github.com/socialvibe/truex-ctv-web-reference-app/blob/develop/platforms/Vizio/README.md) describes retail SmartCast web-app deployment. We did not find a repository license at review time, so Horizon uses only this attribution/reference and redistributes no code from it.
- [`vindeckyy/smartcast-backdoor`](https://github.com/vindeckyy/smartcast-backdoor) documents security research on a different model. The repository identifies MIT licensing. It was consulted as research context only; Horizon includes none of its exploit code or payloads.

The Vizio name and SmartCast marks belong to their respective owners. Horizon is an independent community project and is not endorsed by Vizio.
